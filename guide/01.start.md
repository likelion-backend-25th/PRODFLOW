# 1장 팀 프로젝트 시작
- 레포지토리는 멋쟁이 사자처럼의 Organizations 에서 생성
- 팀 프로젝트용 레포지토리 생성은 PL(Project Leader) 혼자 진행하고 팀원은 [5. 레포지토리 clone](#5-레포지토리-clone)만 진행

# 1 레포지토리 생성

- github 로그인
- Github organizations 접속
  - <https://github.com/likelion-backend-25th>
- Repositories > New repository
  - Repository name: `프로젝트명`
    + 예시: `project-ms`
  - Description: 프로젝트 설명
    + 예시: `BackEnd BootCamp 25기 3차 심화 프로젝트 0팀 하루배움`
  - Choose visibility: Public 선택
  - Create repository

# 2 Collaborators 추가

- Settings > Collaborators and teams > Add people
  - 팀원 계정 입력
  - Choose a role: Admin
  - Add selection

# 3 프로젝트 생성

## 3.1 Spring Boot 프로젝트 생성

### 3.1.1 새 프로젝트 시작
- IntelliJ IDEA > File > New > Project...

### 3.1.2 Spring Boot 선택
- 생성창 좌측의 Generators 목록 중에서 Spring Boot 선택

### 3.1.3 프로젝트 기본 정보 입력
- Name: `project-ms`
- Location(프로젝트를 생성할 폴더 선택): `c:/bebc25/project-ms`(예시)
- Language: Java
- Type: Gradle - Groovy
- Group: `net.likelion.bebc25`
- Artifact: `project-ms`
- Package name: `net.likelion.bebc25.lms`
- JDK(컴파일러/런타임): 25 Eclipse Temurin
- Java(코드내의 Java 문법 버전): 25
- Packaging: Jar
- Configuration: YAML
- Next 클릭

### 3.1.4 스프링 부트 버전 및 의존성 라이브러리 선택
- Spring Boot: 4.1.1
- Dependencies
  - Developer Tools > `Lombok`: 자바 보일러플레이트 코드 자동화
  - Web > `Spring Web`: 웹 MVC 및 RESTful API 지원
  - Security > `Spring Security`: 애플리케이션 보안 및 접근 제어
  - Security > `OAuth2 Client`: 소셜 로그인 인증 연동
  - SQL > `Spring Data JPA`: 엔티티 영속성 및 ORM 데이터 접근 계층 지원
  - SQL > `MySQL Driver`: MySQL 데이터베이스 연동 드라이버
  - I/O > `Validation`: 요청 DTO 유효성 검증
- Create 버튼 클릭

### 3.1.5 build.gradle 외부 의존성 추가
- Spring Initializr에서 지원하지 않는 Swagger(OpenAPI), JWT 라이브러리를 `build.gradle`의 `dependencies` 블록에 추가

```groovy
dependencies {
    // ... 기존 의존성 ...

    // Swagger / OpenAPI
    implementation 'org.springdoc:springdoc-openapi-starter-webmvc-ui:3.1.1'

    // JJWT
    implementation 'io.jsonwebtoken:jjwt-api:0.13.0'
    runtimeOnly 'io.jsonwebtoken:jjwt-impl:0.13.0'
    runtimeOnly 'io.jsonwebtoken:jjwt-jackson:0.13.0'
}
```
- Gradle 변경사항 반영 (우측 상단 코끼리 아이콘 클릭 또는 `Ctrl + Shift + O`)

## 3.2 .gitignore 파일에 추가
- 프로젝트 루트의 `.gitignore` 파일 하단에 보안 시크릿 및 개발 환경 설정 파일 제외 항목 추가

```gitignore
# 보안 키 및 환경 변수 파일 유출 차단
**/*.pem
.env*
!.env.example

# OS 생성 파일
.DS_Store
Thumbs.db
```

# 4 깃허브 레포지토리에 push

## 4.1 Git 초기화
- 스프링 부트 서버 중지 후 터미널에서 실행

  ```sh
  git init
  ```

## 4.2 Git 원격 레포지토리 연결
```sh
git remote add origin https://github.com/likelion-backend-25th/[레포지토리명].git
```
  
## 4.3 commit & push
```sh
# 현재 폴더를 포함한 하위의 모든 변경사항을 스테이징 영역에 추가
git add .
# 스테이징 영역에 있는 변경사항을 커밋으로 기록
git commit -m "initial commit"
# 브랜치 이름을 강제로 변경(master일 경우 main으로)
git branch -M main
# 업스트림을 origin/main으로 지정한후 push
git push -u origin main
# 만약 원격 레포지토리에 .gitignore 같은 파일이 이미 있어서 충돌날 경우 강제로 push
git push -u origin main --force
```

# 5 레포지토리 clone

- 팀원들은 위에서 생성하고 초기화가 완료된 레포지토리를 clone해서 프로젝트 시작
  ```sh
  git clone https://github.com/likelion-backend-25th/[레포지토리명].git
  ```
