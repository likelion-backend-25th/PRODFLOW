# 3장 깃허브 프로젝트

# 1. 깃허브 프로젝트란?
- 칸반 보드, 이슈/PR 연동 같은 기능을 제공하는 프로젝트 관리 도구

## 1.1 프로젝트 생성 실습
- Github Repository > Projects > New project > Table
  - Project name: `하루배움 LMS`
  - `Create project`

- 프로젝트에 팀원 추가
  - 생성한 프로젝트 > 우측 상단의 더보기 메뉴(`...`) > Settings > Manage access > Invite collaborators에 팀원 검색해서 `Invite`

## 1.2 뷰 이름 변경 실습
- 생성한 프로젝트 선택
- "View 1" 탭의 화살표 클릭 후 Rename view 선택
- View name: `백로그`
- `Save`

## 1.3 필드 관리 실습
- 화면 우측의 `View` 버튼 선택 후 Fields 선택
- 보고 싶은 항목만 체크
  - Assignees: 작업 담당자
  - Status: 작업 진행 상태
  - Labels
  - Milestone
  - Effort: 복잡도, 작업량
  - Priority: 우선순위

## 1.4 아이템 추가
- 프로젝트에 아이템을 단순히 메모 형태로 추가하거나(Create a draft) 이슈로 만들어서(Create new issue) 연동 가능
  + draft로 추가할 경우 title을 선택해서 Convert to issue 메뉴를 선택하면 이슈로 전환 가능
  + 이슈로 만들 때는 [ 2장 이슈 관리 - 3. 이슈로 지정하는 작업의 규모](./02.issue.md#3-이슈로-지정하는-작업의-규모) 참고

- 실습
  + 프로젝트 아이템 목록 맨 아래에 `You can use Control + Space to add an item` 누르면 프로젝트 아이템 추가 가능
  + `강좌 목록 조회 API 구현` 입력 후 `Create a draft` 선택하거나 `Ctrl + Enter`
  + `이메일 회원가입 API 구현` 입력 후 `Create a draft` 선택하거나 `Ctrl + Enter`

## 1.5 칸반 보드 뷰 추가
- Todo, In Progress, Done 상태를 모아서 관리하는 칸반 보드 스타일의 뷰를 추가
- '+ New View' 탭 > Board
- "View 2" 탭의 화살표 클릭 후 Rename view 선택
- View name: `칸반보드`
- `Save`
