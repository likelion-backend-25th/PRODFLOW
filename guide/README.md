# 프로젝트 진행 가이드

팀 프로젝트를 안정적으로 킥오프하고 실무 수준의 협업 파이프라인을 구축하기 위한 단계별 가이드 문서 모음입니다.

## 목차
- [1장 팀 프로젝트 시작](01.start.md): 팀 레포지토리 생성, Spring Boot 프로젝트 초기화, Git 푸시 및 clone
- [2장 이슈 관리](02.issue.md): 마일스톤, 레이블, 이슈 템플릿 작성 및 이슈 생성 실습
- [3장 깃허브 프로젝트](03.project.md): 프로젝트 보드 생성, 백로그 및 칸반 보드 뷰, 필드 관리
- [4장 코드 컨벤션](04.convention.md): 코딩 컨벤션의 정의, 5대 필수 정의 영역 및 IntelliJ 자동화 설정
- [5장 깃 브랜치 전략 및 협업 워크플로우](05.git.md): main/develop 브랜치 보호 규칙, PR 2인 승인, CI 테스트 자동화 및 충돌 해결 가이드
- [6장 심화 프로젝트 주제 가이드](06.topic.md): 4대 추천 주제(박람회 예약, 영업 견적, 생산 관리, 통합 A/S) 분석, 추천 케이스 및 장단점
