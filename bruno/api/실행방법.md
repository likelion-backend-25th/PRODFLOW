# PRODFLOW Bruno 컬렉션

기존 `bruno/api`와 시연용 컬렉션을 이 폴더 하나로 합쳤다.

1. 로컬 서버를 8080으로 띄운다.
2. Bruno에서 `bruno/api` 폴더를 Open Collection으로 연다.
3. 환경은 `local`을 선택한다. 주소는 `baseUrl`이다.
4. Collection Runner로 `01`부터 `17`까지 순서대로 실행한다. 대시보드에는 기간을 거꾸로 넣은 400 요청과, 실적이 없는 기간의 0% 요청이 들어 있다.
5. `18 외부연동과 시드변경`은 PortOne, 공공데이터, 택배 조회, 메일, 시드 수주 상태를 바꾼다. 필요할 때만 따로 실행한다.
6. `19 로그아웃`은 마지막에 실행한다. Access Token은 만료 전까지 남고 Refresh Token만 폐기된다.

시드 계정 `admin1`, `order1`, `prod1`, `inquiry1`은 이미 비밀번호 변경이 끝난 계정이다.
러너는 최고 관리자로 로그인한 뒤 수주 관리자, 생산 현장 관리자, 업무 조회 담당자를 새로 만들고,
임시 비밀번호 로그인, 업무 API 거부, 비밀번호 변경, 재로그인 순서로 토큰을 만든다.
이후 요청은 그 토큰과 응답에서 저장한 ID를 사용한다.

임시 비밀번호는 12자 `TempPass123!`, 변경 비밀번호는 `Bruno1234!`다.
같은 컬렉션을 다시 실행하면 이메일에 실행 시각이 붙어 계정이 새로 만들어진다.
거래처 엑셀은 `files/clients.xlsx`라서 같은 이메일로 다시 가져오면 중복될 수 있다.
